# Sales-Performance-Dashboard (Microsoft Excel)

## Overview

This project is an interactive sales dashboard built entirely in Microsoft Excel using the Sample Superstore dataset.

The dashboard demonstrates data cleaning, Pivot Tables, Pivot Charts, Slicers, conditional formatting, and business analysis techniques commonly used in reporting and data entry roles.

---

## Features

- Data Cleaning
- Excel Tables
- Conditional Formatting
- Profit Margin Calculation
- Pivot Tables
- Pivot Charts
- Interactive Slicers
- Dashboard Design
- Business Insights

---

## Dashboard Insights

- West region recorded the highest sales and profit.
- South region recorded the lowest sales.
- Technology generated the highest sales and profit.
- Furniture generated the lowest overall profit.
- The top two customers contributed significantly more sales than the remaining top 10 customers.
